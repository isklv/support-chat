Справка: Как настроить Telegram-бота для группы поддержки
1
Создайте бота
Откройте @BotFather в Telegram, отправьте /newbot, задайте имя и username. Скопируйте полученный Bot Token.
2
Создайте группу с темами
Создайте супергруппу в Telegram и включите «Темы» (Topics / Forums) в настройках группы. Это позволит разделять обращения пользователей по отдельным веткам.
3
Сделайте бота админом
Добавьте созданного бота в группу и назначьте его Администратором с правами управления темами и отправки сообщений.
4
Узнайте Chat ID группы
Добавьте в группу бота @RawDataBot или @userinfobot. Скопируйте Chat ID (начинается с -100...), после чего удалите инфо-бота.

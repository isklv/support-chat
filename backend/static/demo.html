💬 Демо виджета обратной связи (Support Chat)

Это пример страницы, на которую встроен виджет обратной связи с поддержкой через Telegram бота.

1. Встраивание через тег <script>

<script
  src="http://localhost:8080/widget.js"
  data-api="http://localhost:8080"
  data-title="Служба заботы"
  data-color="#2563eb"
  data-position="bottom-right"
  data-lang="ru">
</script>

2. Использование в React:

import { SupportWidget } from 'support-chat-widget';

export function App() {
  return (
    <SupportWidget
      apiUrl="https://chat.example.com"
      primaryColor="#2563eb"
      lang="ru"
    />
  );
}

Нажмите на синюю круглую кнопку в правом нижнем углу экрана, чтобы протестировать диалог и отправку скриншотов!

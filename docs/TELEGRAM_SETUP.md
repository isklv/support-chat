# Подробная настройка Telegram-бота и группы с темами

В этой инструкции пошагово описано, как создать бота в Telegram, создать группу с темами (форум-топиками) для ваших операторов и получить все нужные идентификаторы для `.env`.

---

## Шаг 1. Создание Telegram-бота через @BotFather

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)** (с синей галочкой).
2. Отправьте команду `/newbot`.
3. Введите название для бота (например, `MyCompany Support Bot`).
4. Введите юзернейм для бота, заканчивающийся на `bot` (например, `mycompany_support_bot`).
5. **BotFather** пришлет сообщение с токеном вида:
   ```
   1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```
6. Сохраните этот токен в переменную `TELEGRAM_BOT_TOKEN`.

---

## Шаг 2. Создание супергруппы с темами (Forum Topics)

1. В Telegram создайте **Новую группу** (New Group).
2. Добавьте в созданную группу вашего бота (по его юзернейму).
3. Перейдите в настройки созданной группы:
   - Нажмите на название группы -> **Редактировать (карандаш)** -> **Управление группой**.
4. Включите опцию **«Темы» (Topics)**:
   - В зависимости от клиента пункт называется *«Темы»*, *«Форум»* или *«Topics»*.
   - *Примечание: в Telegram включение тем доступно для супергрупп любого размера.*
5. Назначьте бота **Администратором**:
   - *Настройки группы -> Администраторы -> Добавить администратора*.
   - Выберите вашего бота.
   - Убедитесь, что боту даны права:
     - ✅ Управление темами (Manage Topics)
     - ✅ Отправка сообщений (Send Messages)
     - ✅ Отправка медиа (Send Media)

## Шаг 3. Как узнать `TELEGRAM_CHAT_ID`

`TELEGRAM_CHAT_ID` для супергруппы — это отрицательное число, обычно начинающееся с `-100...`.

Есть несколько простых способов узнать его:

### Способ А. Через @userinfobot или @RawDataBot
1. Временно добавьте бота **[@RawDataBot](https://t.me/RawDataBot)** в вашу группу.
2. Он сразу же пришлет JSON с информацией о чате. Найдите блок `"chat"`:
   ```json
   "chat": {
     "id": -1001987654321,
     "title": "Support Team",
     "type": "supergroup"
   }
   ```
3. Скопируйте число `-1001987654321` — это и есть ваш `TELEGRAM_CHAT_ID`.
4. Удалите `@RawDataBot` из группы.

### Способ Б. Через веб-версию Telegram (Web A / Web K)
1. Откройте группу в браузере (https://web.telegram.org).
2. Посмотрите на URL в адресной строке:
   `https://web.telegram.org/k/#-1987654321`
3. Добавьте `-100` перед числом, если его там нет (например, `-1001987654321`).

## Шаг 4. Выбор режима: Polling или Webhook

### Режим 1: Polling (Рекомендуется для быстрого старта)
```env
TELEGRAM_MODE=polling
```
- **Преимущества**: работает без настройки домена, HTTPS и reverse proxy. Можно запускать прямо на ноутбуке или локальном сервере.
- Бот сам непрерывно опрашивает Telegram через HTTPS Long Polling.

### Режим 2: Webhook (Для высоких нагрузок)
```env
TELEGRAM_MODE=webhook
WEBHOOK_URL=https://chat.yourdomain.com/api/v1/support/telegram/webhook
```
- Telegram мгновенно отправляет POST-запрос на ваш сервер при каждом ответе оператора.
- Требуется действительный SSL/TLS сертификат (например, бесплатный от Let's Encrypt).
